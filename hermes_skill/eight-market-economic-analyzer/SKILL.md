# Eight Market Economic Analyzer

这是独立的新八市场系统，不是旧 30 指标日报的升级版。旧系统的采集器或投递器只能作为可替换工具使用；旧 JSON、旧市场状态、旧报告章节和旧 Hindsight 流程均不是本技能的设计依据。

## 边界

本技能只分析 `nextgen/output/market-packages/<date>/` 中的八个市场包，不读取旧 30 指标 JSON，不直接查询 DuckDB，不增加目录外指标，不启动 Telegram 投递。

定量计算全部由程序完成。AI 只负责市场阶段、证据关系、四期限情景、失效条件、错误代价和跨市场传导。报告是每日研究材料，不是自动交易指令。

首次生成结果时就直接使用简体中文，不设置任何“先生成英文、再翻译”的阶段。除 schema 固定枚举、指标 ID、通用金融缩写和 URL 外，所有自然语言字段、证据理由、事件摘要、综合论述、失效条件与报告正文必须是中文。英文新闻来源必须概述为中文，不得直接复制英文标题、摘要或论述。

## 执行流程

1. 使用项目 Python 执行 `python -m market_system.cli prepare-ai --packages <package_dir> --output <run_dir>`。
2. 读取 `market-jobs.json`，通过 `delegate_task` 分别运行八个市场任务。同时最多两个，避免本机资源和工具拥塞。所有任务均不指定模型或 provider，也不使用 `-m` 覆盖；统一由 Hermes 当前主模型和完整 fallback 链按配置顺序接管。
3. 每个任务严格按照 `market-analysis-v1.schema.json` 写一个 JSON。可使用 `web_search` 搜集截至决策时点已经发生的重大事件；最多八条，必须含日期和 URL，不得把新闻当成定量事实。
4. 每份结果执行 `validate-market`。失败时只允许一次结构修复，不重新解释市场；第二次失败则停止该日流程，不用旧结果顶替。
5. 八份均通过后执行 `prepare-cross`。主任务继续使用同一 Hermes fallback 链读取 `cross-market-job.json` 和八份结果，按 `cross-market-analysis-v1.schema.json` 写 `cross-market.json`。
6. 执行 `validate-cross`；通过后执行 `render-report`。未通过不得投递或写入 Hindsight。
7. 通过后由程序生成全新的八市场趋势与预测报告，并把预测写入 DuckDB 台账。该流程不依赖旧日报 JSON、旧报告模板或 Hindsight。

## 分市场判断原则

- 阶段先于方向，只能选择：趋势延续、技术反弹、假突破、顶底转换、震荡、证据不足。
- 单日价格不能独立确认趋势。至少要有波动率、美元/利率、流动性、资金或杠杆中的一类独立证据；没有则降级为证据不足或低置信。
- 核心、支持、矛盾证据均引用输入路径，例如 `indicators.sp500.statistics.1m.return`，不要在理由里复制大量数字。
- 波浪结果是机械摆动候选，不是确定浪数。Rule of 7 目标只有在方向、锚点和失效位均有效时才采用。
- 斐波那契回撤与扩展是辅助价位工具，只能使用输入中程序确认的最近完整摆动高低点。优先说明 38.2%/50%/61.8%/78.6% 回撤和 127.2%/161.8%/200%/261.8% 扩展中距离现价最近、且与机械支撑阻力或其他工具共振的价位；不得自行更换锚点，不得单独据此提高方向置信度。
- 每个市场必须给出 1 日、1 周、1 月、3 月四个独立判断及置信度。
- 每个阶段必须有失效条件与判断错误代价。
- ROI 和风险收益比只在存在可验证的现价、目标和失效位时填写；风险收益比小于 2 时置空并作为观察，不输出仓位或交易指令。
- 周度/月度数据不冒充当日数据；使用其最近公布日并说明发布滞后。缺失指标不允许用历史最近值伪装成当日值。

## 跨市场综合原则

- 只读取已通过门禁的八份市场结果，不重新分析原始价格。
- 优先检查美元与利率、全球风险偏好、中国需求、能源供给、商品通胀、杠杆去化六类传导。
- 每条传导必须给出起点、终点、机制、证据引用和失效条件。
- 明确互相冲突的市场信号并给出 Plan B，不为形成统一叙事而抹掉矛盾。
- DXY、USD/JPY、USD/CNH 是最高权重外汇节点，分别用于全球美元流动性、日元套息/去杠杆、中国资本流动与亚洲风险偏好。

## 路径

- 项目：以调用时的工作目录或 `EIGHT_MARKET_PROJECT_ROOT` 为准。
- Python：使用项目虚拟环境或 `EIGHT_MARKET_PYTHON`。
- 市场 schema：`schemas/market-analysis-v1.schema.json`
- 综合 schema：`schemas/cross-market-analysis-v1.schema.json`

技能本身不创建、修改调度，也不直接投递 Telegram；这些动作只由外层生产任务负责。
